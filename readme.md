# Coffee Shop Website

A modern coffee shop website built with HTML, CSS, and JavaScript, demonstrating key web development concepts.

## Project Overview

This project creates an interactive coffee shop website showcasing products and services with a dynamic user experience.

## Features

- **DOM Manipulation**: Dynamic content updates and interactive elements
- **Local Storage**: Persistent data storage for user preferences and cart items
- **Responsive Design**: Built with Tailwind CSS for mobile-first styling
- **Interactive UI**: JavaScript-powered features for enhanced user engagement

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Styling with Tailwind CSS framework
- **JavaScript**: DOM manipulation and local storage integration

## Getting Started

1. Clone or download the project
2. Open `index.html` in your web browser
3. Explore the coffee shop interface and interact with features
